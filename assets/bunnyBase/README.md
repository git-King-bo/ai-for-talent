# Bunny Base Transparent Frames

This folder contains the active transparent PNG frames used by the app.

Source images with the original visible/checker background are backed up in `assets/bunnyBaseRaw`.

To regenerate this folder from the raw images:

```bash
pnpm transparent:bunny
```

Current action groups:

- `idle_01.png` to `idle_04.png`
- `blink_01.png` to `blink_02.png`
- `turn_01.png` to `turn_04.png`
- `kiss_01.png` to `kiss_04.png`
